## 🇧🇩 About AmarBazarBD

```yaml
name: AmarBazarBD
tagline: Bangladesh-এর নিজস্ব App Store
url: https://akrakib.github.io/amarbazar/
database: Firebase Firestore
hosting: GitHub Pages
language: Bilingual (English + বাংলা)
status: 🟢 Live & Active
```

AmarBazarBD হলো একটি **Bangladeshi app discovery platform** যেখানে local developers তাদের apps showcase করতে পারে এবং users সহজে খুঁজে download করতে পারে — সম্পূর্ণ বিনামূল্যে।

## 🚀 How to Use

**For Users:**
1. Visit [akrakib.github.io/amarbazar](https://akrakib.github.io/amarbazar/)
2. Browse or search for apps
3. Click **Get App** to download

**For Developers:**
1. Click **Submit App** in the navbar
2. Fill in your app details + download link
3. Wait for admin approval (24–48 hours)

**For Admin:**
1. Login with admin email
2. Go to **Admin ⚙️** panel
3. Approve or reject pending apps
